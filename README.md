# 🖼️ Image Gallery

A clean and responsive **Image Gallery** created using **HTML**, **CSS**, and **JavaScript**. It allows users to view images in a grid layout, hover for visual effects, and open a larger preview using a lightbox-style viewer.

---

## ✨ Features

- Responsive grid layout for different screen sizes
- Smooth image hover effects using CSS
- Lightbox-style image preview using JavaScript
- Click to enlarge and close preview
- Easy to customize and extend

---

## 🛠️ Technologies Used

- **HTML5** – For image structure and layout
- **CSS3** – For styling, transitions, and responsiveness
- **JavaScript** – For lightbox functionality and interactions
